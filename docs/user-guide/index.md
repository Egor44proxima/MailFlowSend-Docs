# Робочі області

Accepted UX baseline має 20 основних operator workspaces:

**Огляд · Клієнти · CSM · Документи · База розсилки · Кампанії · Борг · Черга · Доставка · Недоставка · Історія · Аналітика · Моніторинг · Вхідна пошта · DSN огляд · Діагностика · Системний журнал · Відновлення · Модулі · Налаштування**

Інтерфейс розділяє read-only evidence, controlled operations, authoring та configuration actions. Візуальний action context не замінює backend safety guards.
