# Перший запуск

Після старту застосунку перевірте health/status indicators та відкрийте **Огляд** або **Діагностику**.

1. Перевірити SQLite OK.
2. Перевірити runtime modules.
3. Перевірити runtime mode.
4. Відкрити **Клієнти**.
5. Відкрити **Чергу**, **Доставку** та **Історію**.
6. Перед реальною кампанією пройти повний preflight.

!!! warning
    Не використовуйте production send як спосіб перевірити працездатність. Для цього існують DEV/LOCAL_TEST сценарії та acceptance tooling.
