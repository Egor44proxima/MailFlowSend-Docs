# Політика публічної документації

Цей GitHub Pages repository є **public-safe projection** технічної документації.

## Дозволено

- architecture;
- operator workflows;
- state semantics;
- accepted public baseline;
- generic examples;
- sanitized diagrams;
- release summaries.

## Не публікуємо

- credentials / passwords / tokens;
- recipient email/name evidence;
- raw Message-ID;
- production databases;
- diagnostic bundles;
- attachment content;
- local filesystem evidence з персональними шляхами;
- runtime screenshots із персональними даними без redaction.

Raw engineering acceptance docs можуть лишатися у private application repository; на Pages публікується sanitized summary.
